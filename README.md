# Chill Night - Obsidian Theme 🌙

A cozy, dark, and minimalist theme for Obsidian, designed to provide a "chill" environment for deep thinking and focused writing. This theme uses the **Chill Night** color palette—a blend of deep midnight blacks and soft pastel accents.

![Theme Preview](screenshot.png)

# Features

- **Chill Night Palette:** Custom midnight background (`#0f0e0f`) with vibrant yet soft accents in pink, purple, and teal.
- **Enhanced Typography:** Optimized for readability in both editing and reading modes.
- **Accent-Coded UI:** Color-coded headers, links, and checkboxes to help you navigate your notes at a glance.
- **Syntax Highlighting:** Beautifully styled code blocks that match the overall aesthetic.

## Color Palette

- **Editor Background:** `#0f0e0f` (Midnight)
- **Variables / Pink:** `#fb779c`
- **Functions / Blue:** `#61afef`
- **Headers / Purple:** `#dd7be5`
- **UI Accents / Teal:** `#08cad3`
- **Comments / Gray:** `#58585a`

## Installation

### Via Obsidian (Recommended)
1. Open **Settings** in Obsidian.
2. Go to **Appearance** > **Themes** > **Manage**.
3. Search for `Chill Night` (if published) and click **Install and Use**.

### Manual Installation
1. Download the `theme.css` and `manifest.json` files.
2. Open your Obsidian vault folder.
3. Navigate to `.obsidian/themes/`.
4. Create a folder named `Chill Night` and paste the files inside.
5. In Obsidian, go to **Settings** > **Appearance** > **Theme** and select `Chill Night`.

## Development & Customization

If you want to modify the theme:
- All core variables are defined under `body.theme-dark`.
- Feel free to adjust the `--chill-night-palette` hex codes in `theme.css` to suit your personal style.
